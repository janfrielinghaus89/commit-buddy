# Commit-Buddy

An AI-powered CLI tool that generates Conventional Commit messages
from staged Git changes.

## Features

- AI-generated Conventional Commits
- Supports Ollama, OpenAI and Anthropic
- Local-first workflow with Ollama
- Interactive commit confirmation
- Configurable via environment variables
